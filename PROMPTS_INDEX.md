## Как использовать промпты

### Для каждой задачи:

1. **Откройте соответствующий файл промпта** (например, `PROMPTS_TASK_2.md`)

2. **Выполните в порядке:**
   - Прочитайте **Цель** и **Зависимости**
   - Убедитесь, что зависимости завершены
   - Прочитайте `IMPLEMENTATION_PLAN.md` и `frontend/README.md`
   - Проверьте текущее состояние кода: `git status`, `git log --oneline`

3. **Следуйте разделу "Работы":**
   - Реализуйте **Данные и модели** (сущности, миграции)
   - Реализуйте **API (Backend)** (сервисы, контроллеры)
   - Реализуйте **Фронтенд** (компоненты, маршруты, клиент)

4. **Делайте коммиты** в рекомендуемом порядке (см. "Обязательные коммиты"):
   ```bash
   git add .
   git commit -m "task/N-feature-name: <описание>

Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>"
   ```

5. **Проверьте критерии готовности** из раздела "Критерии готовности"

6. **Запустите проверки** из раздела "Что проверить перед финализацией":
   ```powershell
   dotnet build backend.sln --no-restore
   dotnet test backend.sln --no-restore
   npm run build
   docker compose up --build
   ```

7. **Обновите IMPLEMENTATION_PLAN.md** таблицу статуса

## Критические точки для каждой задачи

### Задача 2: Школа, ученики, курсы
- ⚠️ **Авторизация:** преподаватель видит только своих учеников, администратор — всех
- ⚠️ **Миграция:** добавить индексы на email, FK школа-ученик
- ⚠️ **Данные:** заметки видны только автору и администратору

### Задача 3: Оплаты и два баланса
- ⚠️ **Точность:** используйте `decimal` для денег, а не `float`
- ⚠️ **Идемпотентность:** повторная запись платежа не дублирует начисления
- ⚠️ **Граница 5 часов:** тестируйте ровно в 5 часов, за секунду до/после

### Задача 4: Календарь и повторения
- ⚠️ **Часовой пояс:** всё в UTC в БД, преобразуйте при чтении
- ⚠️ **DST:** обработайте переходы на летнее/зимнее время корректно
- ⚠️ **Редактирование серии:** будущие экземпляры обновляются, прошедшие остаются неизменены

### Задача 5: Домашние задания
- ⚠️ **Безопасность:** используйте GUID-имена файлов, проверьте MIME type, защитите от LFI
- ⚠️ **Размер файла:** максимум 5 МБ, проверьте на сервере
- ⚠️ **Доступ:** преподаватель видит своих учеников, студент — только себя

### Задача 6: Дашборд
- ⚠️ **N+1 запросы:** используйте `Include()` для связей в Entity Framework
- ⚠️ **Производительность:** оптимизируйте для 100+ учеников
- ⚠️ **Параметры:** `LowBalanceThreshold` и `HighDebtThreshold` читайте из конфига

### Задача 7: Сквозная проверка
- ⚠️ **Новая БД:** миграции должны работать на чистой БД
- ⚠️ **Существующая БД:** не теряйте старые данные
- ⚠️ **Docker Compose:** volume должен сохранять данные после перезагрузки
